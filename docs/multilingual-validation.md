# 多言語対応の検証記録

2026年9月22日、バージョン0.4.0で、共通の文法Stepテンプレートに対する多言語対応を検証した。配布物は単一のユーザースクリプトで、実行時の外部依存は追加していない。

## 追加検証と修正（2026年9月22日）

異常系の回帰テストで、iframeの読み込み先が別教材へ転送されても、本文構造が同じなら現在のStepに混在する不具合を再現した。これはテストで転送を発生させた結果であり、実サイトで転送が発生したという記録ではない。

読み込み完了時に、要求した教材と実際のオリジン・パスが一致するかを検証するよう修正した。再試行でも転送先を再読込せず、要求元のURLを設定し直す。修正後の自動テストは12件すべて成功した。追加した検査は、各タブからの起動、転送エラーと復旧、一括取得失敗時のZIP保存抑止、幅390pxでの折りたたみと音声操作である。

実サイトでは、初回の22 Stepに、各区分の末尾から教材のあるコースを選んだ中間・末尾Lessonの43 Stepを加えた。修正後のスクリプトで、22区分・重複なしの65 Step・195ページの取得先、iframe表示、横方向のはみ出しを検査し、すべて成功した。アラビア語フスハーの末尾コースにはLessonリンクがなかったため、その前の教材があるコースを使った。通言語は選択対象のLessonが一つだったため、追加は1 Stepとなった。

韓国語・ドイツ語・中国語・日本語・ウルドゥー語・アラビア語エジプト方言では、例文（存在しない場合は解説）から統合画面を起動し、各1件の実MP3で再生時間が進み、メディアエラーがないことを確認した。同じ6区分で幅390pxへ切り替え、本文と外枠の横方向のはみ出しがないことを検査した。韓国語・ウルドゥー語は画像でも配置を確認した。音声を聴き比べて教材の発音や内容を評価したものではない。

結果は [追加検証の記録](revalidation-20260922.json) に保存した。修正後のスクリプトのSHA-256は `831dc9d5f45c420b0382fc636018511ad2b3ae7e2df545aa99e2d52135f90b5c`。以下は比較用に残した初回の記録であり、当時のハッシュは修正前のものとなる。

## 初回のローカル回帰検証

`npm test` の8テストが成功した。fixture上で次の動作を確認している。

- 韓国語の4画面、iframeでの再帰防止、解説と例文の一意な完全一致、重複・不一致の除外
- 音声の代理操作、練習問題の正解欄表示、ZIPの生成・ダウンロード、再読み込み
- 方言コード、タブ文言・タグの変更、例文・練習問題の欠落
- 別言語・別Step・別オリジン・別分野のタブリンクを読み込まないこと
- 解説だけにある音声、原文・訳・発音表記の分離、英字を含む教材番号と右から左の原文の分離
- 原文が同じでも訳が異なる用例には再生ボタンを追加しないこと
- 表記切り替え後も各セクションの教材番号を保持すること
- 言語別の折りたたみ保存、韓国語の旧設定の継承、通常表示指定と未知のDOMの保全
- 配布版のURL検証による外部サイト・HTTP・別分野・未知の階層の除外

fixtureの音声関数は呼び出し内容を記録する代用品で、MP3も検証用のダミーである。音声を聴いた検証には数えない。

## 設計上の判断

調査した範囲では本文・ナビゲーションの基本構造が共通だったため、言語別の設定一覧は不要と判断した。ページ数は言語内でも変わるため、タブの実リンクから決める。原文・訳・発音表記も要素の有無で判別する。

URLの推測フォールバックは削除した。共通の本文・タブ・見出しを確認できないページでは統合処理を開始せず、原表示を残す。今後の拡張でも、確認した構造の差をfixtureに追加してから、共通の取得処理に必要な対応だけを加える。

音声の集約元は例文、例文ページがなければ解説という優先順位に限定した。両ページの全音声を統合すると同じ音声の重複や異なる用例の対応付けが増えるため、今回はその機能を追加していない。集約されない解説内の音声は元ボタンで利用できる。
