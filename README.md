# TUFS 文法・1画面表示

東京外国語大学言語モジュールの文法コースを、カード・解説・例文・練習問題のページを行き来することなく、1画面でまとめて学習できるようにするユーザースクリプトです。韓国語・英語・日本語・中国語・アラビア語など、共通のページ構造を持つ教材に対応します。

> [!IMPORTANT]
> 本ツールは個人が開発した非公式のユーザースクリプトであり、東京外国語大学が提供・公認するものではありません。大学への問い合わせは行わず、不具合の報告や要望は本リポジトリの [Issues](https://github.com/gooftok/tufs-grammar-unified-view/issues) へお寄せください。

## インストール手順

### 1. ユーザースクリプト管理拡張機能の導入

利用しているブラウザに対応した拡張機能をインストールします（すでにいずれかを導入している場合は手順2へ進んでください）。

- Chromium系ブラウザ（Chrome、Edge など）: [Tampermonkey](https://www.tampermonkey.net/)
- Firefox など: [Violentmonkey](https://violentmonkey.github.io/get-it/)

### 2. スクリプトのインストール

[tufs-grammar-unified-view.user.js をインストールする](https://raw.githubusercontent.com/gooftok/tufs-grammar-unified-view/main/tufs-grammar-unified-view.user.js)

リンクを開くと拡張機能のインストール画面が表示されるので、「インストール」を選択します。

### 3. 文法ページの表示

[文法モジュールの言語一覧](https://www.coelang.tufs.ac.jp/mt/index_g.html)からコースを選び、各Stepを開くと、自動的に1画面表示へ切り替わります。言語の事前設定は不要です。共通の本文・タブ・見出しが見つからないページでは、元の表示を維持します。

> [!NOTE]
> スクリプトのアップデートは、拡張機能の自動更新機能によって適用されます。

## 主な機能

- カード・解説・例文・練習問題の1画面統合表示
- 前後のStepへの移動ボタン、およびLesson一覧への復帰ボタン
- 各セクション（カード、解説、例文、練習問題）の個別折りたたみ
- 例文音声の再生と個別ダウンロード
- サイドバーから取得できる音声ファイルのZIP一括ダウンロード
- 解説本文への音声再生ボタン配置（解説と例文の文面が1対1で完全一致する場合のみ）
- 例文ページがない教材では、解説内の音声をサイドバーに表示
- 原文・訳・発音表記が分かれた教材、右から左へ読む原文の表示
- 韓国語の語基式・語幹式・併記式など、見出し内にある教材の表記切り替え
- 言語ごとの折りたたみ状態の保存（旧版の韓国語設定は引き継ぎ）

## 通常表示への切り替えと無効化

- **特定ページでの通常表示**: 画面上部の「元のページを表示」を選択すると、URLに `?unified=0` が付与された通常ページが開きます。レイアウト崩れなどが生じた際の退避手段としても利用できます。
- **一時的な無効化**: 常に元の表示へ戻す場合は、拡張機能（Tampermonkey や Violentmonkey）のメニューから本スクリプトを無効化します。
- **アンインストール**: 不要になった場合は、拡張機能の管理画面から本スクリプトを削除します。

## 対象ページと影響範囲

本スクリプトの動作対象は、東京外国語大学言語モジュールにおける、次のURL形式と共通テンプレートを持つ文法コースの各Stepです。`<言語コード>`には `ko`、`ja`、`ar-eg` などが入ります。

```text
https://www.coelang.tufs.ac.jp/mt/<言語コード>/gmod/courses/<コース>/lesson.../step.../<ページ種別>/<教材番号>.html
```

実行時には、開いたページがカード・解説・例文・練習問題のいずれかに該当するかを判定します。

| ページ | 動作 |
| --- | --- |
| 共通テンプレートの文法Step（カード・解説・例文・練習問題） | 言語・方言を問わず統合画面を表示する |
| 会話・発音・語彙など、文法以外の分野 | 実行しない |
| 言語トップ、コース・Lessonの一覧 | 実行しない |
| 東京外国語大学以外のWebサイト | 実行しない（マッチ対象外） |
| 想定外のURL構造やテンプレートを持つページ | 何も変更せず終了する |

誤動作を防ぐため、拡張機能のメタデータ（`@match`）、スクリプト内部のURL検証、本文・タブ・見出しの構造確認で実行を制御しています。各セクションの読み込み先は、同一オリジン・同じ言語・同じStepのタブ内リンクから取得します。各セクションを表示するiframe内部で再帰的に起動しないよう、最上位フレーム（`window.top === window.self`）でのみ実行します。

バージョン0.4.0では、2026年9月22日に公式の文法一覧にある22区分から、先頭・途中・末尾の計65 Step・195ページの読み込みと統合表示を確認しました。対象は英語、ドイツ語、フランス語、スペイン語、ポルトガル語、ロシア語、中国語、朝鮮語、モンゴル語、インドネシア語、マレーシア語、フィリピノ語、ラオス語、ベトナム語、カンボジア語、ウルドゥー語、アラビア語3区分（フスハー・エジプト方言・シリア方言）、トルコ語、日本語、通言語です。これは代表Stepでの確認範囲であり、全コース・全Stepの検証ではありません。

## プライバシーと安全性

- アクセス解析や利用状況ログの外部送信は行いません。
- 外部CDNや外部ライブラリは読み込まず、単一のスクリプトファイルのみで完結して動作します。
- ブラウザ拡張機能の特権APIを要求しません（`@grant none`）。
- 各セクションの開閉状態は、利用環境の `localStorage` にのみ保存します。
- 音声ファイルの一括ダウンロード機能は、ボタン押下時に同一オリジン内のMP3ファイルのみを取得します。
- クライアント側で表示を整えるのみであり、大学サーバー上の教材データを改変する処理はありません。

## 音声機能の仕様

画面右側に配置される音声サイドバーの再生ボタンは、元ページに定義されている音声再生関数を代理で呼び出します。取得元は例文ページを優先し、例文へのリンクがない場合は解説ページを使います。ダウンロードURLが取得できないなど、サイドバー側へ移行できない操作を含む項目については、本文の元ボタンをそのまま残します。

原文・訳・発音表記が別要素になっている教材では、それぞれを分けて表示します。一つの要素に用例がまとまる教材では、従来の番号・括弧による分割を使います。右から左へ読む原文は、教材番号と文字方向の判定を分離しています。

ZIP一括ダウンロード機能は、同一オリジン上に配置されたMP3ファイルのみを対象として単一のZIPファイルにまとめます。通信エラーなどで1件でも取得に失敗した場合は、欠落した状態での保存を防ぐためダウンロード処理を中断します。ブラウザのメモリ負荷を考慮し、取得上限は最大100件、合計サイズ128 MiBまでに制限しています。

解説セクション内の再生ボタンは、解説本文中の用例と例文セクションの用例テキスト（別要素の訳・発音表記を含む）が、空白等の正規化後に1対1で完全一致する場合に限り追加します。出現順序や部分一致による推測判定は行いません。テキストの不一致や重複がある場合、あるいは定型から外れた用例についてはボタンを追加しません。解説にもともと音声操作がある場合は、その操作を使います。

## 不具合の報告

表示崩れや動作不良などの不具合が発生した場合は、[GitHub Issues](https://github.com/gooftok/tufs-grammar-unified-view/issues/new) より報告してください。報告の際は、以下の情報を添えていただくと調査が円滑に進みます。

- 発生箇所のURL（ブラウザのアドレスバーに表示されているURL）
- 利用ブラウザ（Chrome、Firefox、Edge など）
- 利用している拡張機能（Tampermonkey、Violentmonkey など）
- 再現手順と現象（どの操作を行った際に、どのような表示・動作になったか）
- 現象が確認できる画面のスクリーンショット（可能な場合）

## 既知の制限

- **サイト側の仕様変更**: 本スクリプトは東京外国語大学WebサイトのDOM構造に依存しているため、サイト側のHTML構造やスクリプトが更新された場合は正常に表示できなくなる可能性があります。
- **ページの欠落**: タブが無効なStepでは「このStepには○○がありません」と表示します。タブを判別できない場合はURLの取得失敗として区別します。全ページ種別でURLの推測は行いません。タブ自体がないページは統合表示の対象外です。
- **音声の取得範囲**: 例文ページが存在する場合、解説だけにある追加音声はサイドバーへ集約しません。解説内の元ボタンから再生できます。認識できない音声UIは元ページの操作を残します。
- **iframeの埋め込み制限**: サイト側にiframe埋め込みを制限するHTTPレスポンスヘッダ（`X-Frame-Options` やCSPなど）が設定された場合、該当セクションに読み込みエラーを表示します。
- **音声再生終了の未追跡**: 元ページの再生処理は終了イベントを通知しないため、スクリプト側では正確な再生終了時刻を追跡しません。サイドバーの選択ハイライトは、最後に再生ボタンを押した項目に保持されます。

## 開発環境と検証

元ページのJavaScript実行環境やイベントハンドラとの競合を防ぐため、各教材ページは同一オリジンのiframe内に独立して読み込んでいます。対象とするDOMセレクタ（`#container`、`#content_box`、`#gmodnav`、`.instance` など）は、2026年9月22日の代表Stepで確認しています。

配布スクリプトにビルドやライブラリは不要です。自動テストだけが開発用のPlaywrightを使います。Node.js 20以降とインストール済みのEdgeで実行できます。

```powershell
npm ci
npm test
```

別の対応ブラウザを使う場合は、`TUFS_BROWSER_CHANNEL` を `chrome` などに設定します。拡張機能へのインストール・自動更新は、このテストの対象外です。

0.4.0の検証では、WindowsのEdgeで12件の自動テストが成功しました。韓国語・ドイツ語・中国語・日本語・ウルドゥー語・アラビア語エジプト方言の各1項目で実MP3の再生時間の進行を確認し、同じ6区分では幅390pxで横方向のはみ出しがないことも検査しています。音声内容の正しさや全練習問題の正誤判定は検証していません。

構文チェック:

```powershell
node --check .\tufs-grammar-unified-view.user.js
node --check .\tests\smoke-server.mjs
```

検証用サーバ（テスト用fixture）の起動:

```powershell
node .\tests\smoke-server.mjs
```

検証用サーバを起動すると、4画面のiframe読み込み、再帰実行防止ガード、音声の代理再生、用例突合（完全一致・不一致・重複）、ZIP一括ダウンロード、iframeの高さ自動調整、画面再読み込み時のリスナー解除などをローカル環境で検証できます。配布スクリプトの対象ドメインは変更せず、テストサーバがローカル配信用のヘッダとURLで中継します。

多言語の構造調査と実サイトの再検証は次のコマンドで実行できます。構造調査は公式一覧から各区分の先頭Stepをたどり、タブから最大4ページを取得します。既存の調査記録を保つため、出力JSONには新しいファイル名を指定します。

```powershell
$env:PYTHONUTF8 = "1"
python tests/probe-site.py test-results/site-structure-new.json
node tests/live-smoke.mjs test-results/site-structure-new.json
```

実サイト検証ではスクリプトを一時的にページへ挿入します。取得先とiframe表示を確認し、`test-results/live-smoke.json` と代表ページの画像を出力します。実際の発音の正しさ、全問題の正誤判定、Firefoxや拡張機能固有の挙動までは検証しません。今回の調査・検証結果は [多言語対応の検証記録](docs/multilingual-validation.md) を参照してください。

途中・末尾の教材と実音声の追加検証:

```powershell
python tests/probe-more-steps.py test-results/more-steps-new.json
node tests/live-smoke.mjs test-results/more-steps-new.json test-results/more-live-new.json
node tests/live-interactions.mjs
```

実音声の検証では6区分の各1項目について再生時間の進行を確認し、幅390pxでの表示も検査します。別教材への転送はエラーとして扱い、「再試行」で最初に要求したURLを読み直します。

## 多言語対応を拡張するときの方針

言語ごとの実装ファイルや設定一覧は設けず、共通テンプレートとページが持つ機能から構成を決めます。タブの有無は言語内でもStepごとに変わるため、ページ内の実リンクを根拠にします。教材番号やコース番号も固定しません。

| 教材の差 | 現在の扱い |
| --- | --- |
| 言語・方言コード | URLから取得し、共通処理へ渡す |
| 例文・練習問題の有無、タブの表示文言 | 同じStepの実リンクから種別とURLを取得する |
| 音声の位置 | 例文ページを優先し、存在しなければ解説を使う |
| 原文・訳・発音表記の分かれ方 | 要素の有無で取得方法を選ぶ |
| 表記切り替え | 見出し内にある同じStep・同じ種別のリンクを残す |
| 未知の本文テンプレート | 元ページを保つ |

新しい差に対応する場合は、最初に実ページのURLとDOMの差を確認し、その形をfixtureに加えます。同じ構造なら設定追加は不要です。共通処理で扱えない差が確認された場合だけ、該当するセレクタや取得関数へ小さな対応を加えます。HTML全文の言語別コピーや、未確認の構造への推測対応は追加しません。
