# TUFS 韓国語文法・1画面表示

東京外国語大学言語モジュールの韓国語文法コースを、カード・解説・例文・練習問題のページ間を移動せず、1画面で読めるようにするユーザースクリプトです。

> [!IMPORTANT]
> 東京外国語大学による公式ツールではありません。不具合の連絡は大学ではなく、このリポジトリのIssuesへお願いします。

## かんたんインストール

### 1. ユーザースクリプト用の拡張機能を入れる

- Chrome・Edgeなど: [Tampermonkey](https://www.tampermonkey.net/)
- Firefoxなど: [Violentmonkey](https://violentmonkey.github.io/get-it/)

すでにどちらかを使っている場合、この手順は不要です。

### 2. スクリプトを入れる

**[ここをクリックしてインストール](https://raw.githubusercontent.com/gooftok/tufs-grammar-unified-view/main/tufs-grammar-unified-view.user.js)**

拡張機能の確認画面が開いたら、「インストール」を押してください。コードをコピーして貼り付ける必要はありません。

### 3. 韓国語文法のStepを開く

東京外国語大学言語モジュールの韓国語文法コースを開くと、自動的に1画面表示になります。スクリプトの更新は、拡張機能の自動更新機能を通して配布されます。

## できること

- カード・解説・例文・練習問題を1画面に表示
- 前後のStepへ移動
- Lesson一覧へ戻る
- 各セクションの折りたたみ
- 例文音声の再生と個別ダウンロード
- 現在のStepにある音声をZIPで一括ダウンロード
- 解説と例文の文章が安全に対応付けられる場合、解説内にも再生ボタンを表示

## 元の表示へ戻す・一時停止する

- そのページだけ元の表示にする場合は、画面上部の「元のページを表示」を押します。
- 常に元の表示に戻す場合は、TampermonkeyまたはViolentmonkeyのメニューから「TUFS 韓国語文法・1画面表示」を無効化します。
- 不要になった場合は、拡張機能の管理画面からこのスクリプトを削除できます。

`?unified=0` が付いたページでは統合処理を行いません。表示に問題が起きた場合の退避手段としても使えます。

## 対応範囲と他ページへの影響

対象は、東京外国語大学言語モジュール内の韓国語文法Stepだけです。

```text
https://www.coelang.tufs.ac.jp/mt/ko/gmod/courses/.../lesson.../step.../
```

さらに、実行時にカード・解説・例文・練習問題のいずれかであることを確認します。

|ページ|動作|
|---|---|
|韓国語文法のカード・解説・例文・練習問題|統合表示する|
|韓国語モジュール内の会話・発音・語彙など|実行しない|
|日本語など、韓国語以外の言語モジュール|実行しない|
|東京外国語大学以外のWebサイト|実行しない|
|想定したURL構造ではないページ|何も変更せず終了する|

対象外ページでは、ユーザースクリプト管理拡張のURL判定と、スクリプト内部のURL判定の二段階で処理を止めます。iframe内で誤って再実行されないための判定もあります。

## プライバシーと安全性

- アクセス解析や利用状況の送信はありません。
- 外部ライブラリを読み込みません。
- ユーザースクリプトの特別権限を使いません（`@grant none`）。
- 折りたたみ状態はブラウザ内に保存します。
- 一括DLを押したときだけ、現在のStepにある同一サイト内のMP3を取得します。
- 東京外国語大学のサーバー上の教材を書き換える処理はありません。

## 音声について

右側の音声ボタンは、元ページの再生処理をそのまま呼び出します。安全に移動できない操作がある場合は、元ページ側のボタンを残します。

一括DLは、同一サイト内のMP3だけを1つのZIPへまとめます。1件でも取得に失敗した場合、不完全なZIPは保存しません。上限は100件・合計128 MiBです。

解説内の再生ボタンは、解説と例文の全文が双方で1件ずつ完全一致する場合だけ追加します。順番や部分一致では推測しません。不一致・重複・標準形式ではない例文は変更しないため、別の音声を誤って再生しにくい実装です。

## 困ったとき

[Issuesから不具合を報告](https://github.com/gooftok/tufs-grammar-unified-view/issues/new)できます。次の情報があると確認しやすくなります。

- 問題が起きたページのURL
- 使用ブラウザ
- TampermonkeyまたはViolentmonkeyのどちらを使っているか
- 何をしたとき、何が起きたか
- 可能であれば画面のスクリーンショット

## 既知の制限

- サイト側のHTMLやJavaScriptが変更された場合、正常に表示できなくなる可能性があります。
- 練習問題へのリンクが元ページに存在しないStepでは、「このStepには練習問題がありません」と表示します。存在しないURLは推測しません。
- iframeを拒否する設定へサイト側が変更された場合、該当セクションに読み込みエラーを表示します。
- 音声の正確な再生終了時刻は追跡しません。最後に押した項目だけを選択状態にします。

## 開発者向け情報

2026年7月29日時点の実サイトで、`#container`、`#content_box`、`#gmodnav`、`.instance`、`.instance_t`、`.voiceLinkBox` などの構造を確認しています。教材ページは同一オリジンiframe内に保持し、元ページのJavaScriptを壊さないようにしています。

構文確認:

```powershell
node --check .\tufs-grammar-unified-view.user.js
node --check .\tests\smoke-server.mjs
```

開発用fixture:

```powershell
node .\tests\smoke-server.mjs
```

fixtureでは、4つのiframe、再帰実行防止、音声代理再生、一致・不一致・重複例文の判定、一括DL、動的な高さ変更、再読み込み時の後始末を確認できます。配布用スクリプトの対象サイトは変更せず、fixtureへ返すテスト用コピーだけをlocalhost向けに差し替えます。
