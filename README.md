# TUFS 韓国語文法・1画面表示

東京外国語大学言語モジュールの韓国語文法コースを、カード・解説・例文・練習問題のページを行き来することなく、1画面でまとめて学習できるようにするユーザースクリプトです。

> [!IMPORTANT]
> 本ツールは個人が開発した非公式のユーザースクリプトであり、東京外国語大学が提供・公認するものではありません。大学への問い合わせは行わず、不具合の報告や要望は本リポジトリの [Issues](https://github.com/gooftok/tufs-grammar-unified-view/issues) へお寄せください。

## インストール手順

### 1. ユーザースクリプト管理拡張機能の導入

利用しているブラウザに対応した拡張機能をインストールします（すでにいずれかを導入している場合は手順2へ進んでください）。

- Chromium系ブラウザ（Chrome、Edge など）: [Tampermonkey](https://www.tampermonkey.net/)
- Firefox など: [Violentmonkey](https://violentmonkey.github.io/get-it/)

### 2. スクリプトのインストール

[tufs-grammar-unified-view.user.js をインストールする](https://raw.githubusercontent.com/gooftok/tufs-grammar-unified-view/main/tufs-grammar-unified-view.user.js)

リンクを開くと拡張機能のインストール画面が表示されるので、「インストール」を選択します。

### 3. 韓国語文法ページの表示

東京外国語大学言語モジュールの韓国語文法コース（各Step）を開くと、自動的に1画面表示へ切り替わります。

> [!NOTE]
> スクリプトのアップデートは、拡張機能の自動更新機能によって適用されます。

## 主な機能

- カード・解説・例文・練習問題の1画面統合表示
- 前後のStepへの移動ボタン、およびLesson一覧への復帰ボタン
- 各セクション（カード、解説、例文、練習問題）の個別折りたたみ
- 例文音声の再生と個別ダウンロード
- Step内に含まれる音声ファイルのZIP一括ダウンロード
- 解説本文への音声再生ボタン配置（解説と例文の文面が1対1で完全一致する場合のみ）

## 通常表示への切り替えと無効化

- **特定ページでの通常表示**: 画面上部の「元のページを表示」を選択すると、URLに `?unified=0` が付与された通常ページが開きます。レイアウト崩れなどが生じた際の退避手段としても利用できます。
- **一時的な無効化**: 常に元の表示へ戻す場合は、拡張機能（Tampermonkey や Violentmonkey）のメニューから本スクリプトを無効化します。
- **アンインストール**: 不要になった場合は、拡張機能の管理画面から本スクリプトを削除します。

## 対象ページと影響範囲

本スクリプトの動作対象は、東京外国語大学言語モジュールにおける韓国語文法コースの各Stepです。

```text
https://www.coelang.tufs.ac.jp/mt/ko/gmod/courses/.../lesson.../step.../
```

実行時には、開いたページがカード・解説・例文・練習問題のいずれかに該当するかを判定します。

| ページ | 動作 |
| --- | --- |
| 韓国語文法の各Step（カード・解説・例文・練習問題） | 統合画面を表示する |
| 韓国語モジュール内の別分野（会話・発音・語彙など） | 実行しない |
| 韓国語以外の言語モジュール（日本語・英語など） | 実行しない |
| 東京外国語大学以外のWebサイト | 実行しない（マッチ対象外） |
| 想定外のURL構造を持つページ | 何も変更せず終了する |

誤動作を防ぐため、拡張機能のメタデータ（`@match`）による絞り込みと、スクリプト内部でのURL構造検証の二段階で実行を制御しています。また、各セクションを表示するiframe内部でスクリプトが再帰的に起動しないよう、最上位フレーム（`window.top === window.self`）でのみ実行する制限を設けています。

## プライバシーと安全性

- アクセス解析や利用状況ログの外部送信は行いません。
- 外部CDNや外部ライブラリは読み込まず、単一のスクリプトファイルのみで完結して動作します。
- ブラウザ拡張機能の特権APIを要求しません（`@grant none`）。
- 各セクションの開閉状態は、利用環境の `localStorage` にのみ保存します。
- 音声ファイルの一括ダウンロード機能は、ボタン押下時に同一オリジン内のMP3ファイルのみを取得します。
- クライアント側で表示を整えるのみであり、大学サーバー上の教材データを改変する処理はありません。

## 音声機能の仕様

画面右側に配置される音声サイドバーの再生ボタンは、元ページに定義されている音声再生関数を代理で呼び出します。ダウンロードURLが取得できないなど、サイドバー側へ移行できない操作を含む項目については、例文セクション内の元ボタンを非表示にせずそのまま残します。

ZIP一括ダウンロード機能は、同一オリジン上に配置されたMP3ファイルのみを対象として単一のZIPファイルにまとめます。通信エラーなどで1件でも取得に失敗した場合は、欠落した状態での保存を防ぐためダウンロード処理を中断します。ブラウザのメモリ負荷を考慮し、取得上限は最大100件、合計サイズ128 MiBまでに制限しています。

解説セクション内の再生ボタンは、解説本文中の用例と例文セクションのテキストが1対1で完全一致する場合に限り追加します。出現順序や部分一致による推測判定は行いません。テキストの不一致や重複がある場合、あるいは定型から外れた用例についてはボタンを追加せず、誤った音声が再生される事態を防ぎます。

## 不具合の報告

表示崩れや動作不良などの不具合が発生した場合は、[GitHub Issues](https://github.com/gooftok/tufs-grammar-unified-view/issues/new) より報告してください。報告の際は、以下の情報を添えていただくと調査が円滑に進みます。

- 発生箇所のURL（ブラウザのアドレスバーに表示されているURL）
- 利用ブラウザ（Chrome、Firefox、Edge など）
- 利用している拡張機能（Tampermonkey、Violentmonkey など）
- 再現手順と現象（どの操作を行った際に、どのような表示・動作になったか）
- 現象が確認できる画面のスクリーンショット（可能な場合）

## 既知の制限

- **サイト側の仕様変更**: 本スクリプトは東京外国語大学WebサイトのDOM構造に依存しているため、サイト側のHTML構造やスクリプトが更新された場合は正常に表示できなくなる可能性があります。
- **練習問題の非存在**: 元ページに練習問題へのリンクが存在しないStepでは、「このStepには練習問題がありません」と表示します。実在しないURLを推測して読み込む処理は行いません。
- **iframeの埋め込み制限**: サイト側にiframe埋め込みを制限するHTTPレスポンスヘッダ（`X-Frame-Options` やCSPなど）が設定された場合、該当セクションに読み込みエラーを表示します。
- **音声再生終了の未追跡**: 元ページの再生処理は終了イベントを通知しないため、スクリプト側では正確な再生終了時刻を追跡しません。サイドバーの選択ハイライトは、最後に再生ボタンを押した項目に保持されます。

## 開発環境と検証

元ページのJavaScript実行環境やイベントハンドラとの競合を防ぐため、各教材ページは同一オリジンのiframe内に独立して読み込んでいます。対象とするDOMセレクタ（`#container`、`#content_box`、`#gmodnav`、`.instance` など）は、2026年7月29日時点の実サイト構造に基づいています。

構文チェック:

```powershell
node --check .\tufs-grammar-unified-view.user.js
node --check .\tests\smoke-server.mjs
```

検証用サーバ（テスト用fixture）の起動:

```powershell
node .\tests\smoke-server.mjs
```

検証用サーバを起動すると、4画面のiframe読み込み、再帰実行防止ガード、音声の代理再生、用例突合（完全一致・不一致・重複）、ZIP一括ダウンロード、iframeの高さ自動調整、画面再読み込み時のリスナー解除などをローカル環境で検証できます。配布スクリプトの対象ドメインは変更せず、テストサーバがローカル配信用のヘッダとURLで中継します。
